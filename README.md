# Авалон · Помощник пациента

**https://varta2005.github.io**

Веб-версия приложения для пациентов стоматологической клиники «Авалон» (Санкт-Петербург): памятки после хирургических
операций, план восстановления по дням, врачи, акции и полезные статьи. Работает в любом браузере, офлайн,
ставится на главный экран. Открывается по QR-коду из Android-приложения.

Сайт собирается из репозитория Programs-for-Avalon (папка `web/`) — не редактируйте файлы здесь вручную.
